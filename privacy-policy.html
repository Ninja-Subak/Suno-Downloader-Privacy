Suno Downloader 개인정보 처리방침

시행일: 2026년 8월 13일

본 개인정보 처리방침은 Chrome 확장 프로그램 Suno Downloader (이하 “확장 프로그램”)가 사용자의 정보를 어떻게 처리하는지 설명합니다.

핵심 내용
이 확장 프로그램은 사용자가 선택한 Suno 라이브러리의 음악과 가사를 다운로드하는 기능을 제공하기 위해 필요한 범위에서만 정보를 처리합니다. 확장 프로그램 개발자가 운영하는 별도의 서버에 사용자 데이터를 수집·저장하거나 광고 및 사용자 추적 목적으로 이용하지 않습니다.

1. 확장 프로그램의 목적

Suno Downloader의 단일 목적은 사용자가 자신의 Suno 라이브러리에서 선택한 음악과 가사를 MP3, WAV, SRT, LRC, TXT 등의 형식으로 다운로드할 수 있도록 지원하는 것입니다.

2. 처리하는 정보

2.1 인증 정보

사용자가 Chrome에서 Suno에 로그인한 상태로 확장 프로그램을 사용하는 경우, 확장 프로그램은 Suno의 로그인 세션을 확인하고 인증된 요청을 수행하기 위해 Suno의 인증 세션 쿠키를 사용할 수 있습니다.

이 정보는 사용자의 Suno 라이브러리 조회와 사용자가 요청한 다운로드를 수행하기 위한 목적으로만 사용됩니다. 확장 프로그램 개발자가 이 인증 정보를 별도의 데이터베이스에 저장하거나 판매하지 않습니다.

2.2 웹사이트 콘텐츠

사용자의 요청에 따라 Suno 라이브러리에서 다음과 같은 콘텐츠 정보를 처리할 수 있습니다.

  • 라이브러리의 폴더 정보
  • 곡 제목 및 곡 관련 정보
  • 사용자가 다운로드하도록 선택한 음악 콘텐츠
  • 사용자가 다운로드하도록 선택한 가사 및 가사 타이밍 정보

2.3 확장 프로그램 설정 정보

다운로드 형식, 폴더별 다운로드 설정, 이미 다운로드한 곡을 건너뛰기 위한 기록 등 확장 프로그램의 동작에 필요한 설정은 Chrome의 확장 프로그램 저장소에 저장될 수 있습니다.

3. 정보의 이용 목적

처리되는 정보는 다음 목적에 한하여 사용됩니다.

  • Suno 로그인 상태 확인
  • 사용자의 Suno 라이브러리 및 폴더 조회
  • 사용자가 선택한 음악 다운로드
  • 사용자가 선택한 가사 다운로드
  • 다운로드 형식 및 저장 방식 처리
  • 이미 다운로드한 곡을 건너뛰는 기능 제공
  • 확장 프로그램 설정 유지

4. 정보의 수집·저장·전송

확장 프로그램 개발자는 광고, 분석, 사용자 프로파일링 또는 마케팅을 위해 사용자 데이터를 수집하지 않습니다.

확장 프로그램에는 개발자가 운영하는 별도의 사용자 데이터 수집 서버가 없습니다. 확장 프로그램은 사용자의 브라우저에서 필요한 요청을 수행하며, Suno의 서비스 및 API와 통신할 수 있습니다. 이 과정에서 사용자의 Suno 인증 세션은 Suno 서비스에 대한 인증된 요청을 수행하는 데 사용됩니다.

따라서 사용자가 Suno 서비스를 이용하는 과정에서 Suno가 처리하는 데이터에 대해서는 Suno의 자체 개인정보처리방침 및 이용약관이 적용될 수 있습니다.

5. 제3자 제공 및 판매

  • 사용자 데이터를 판매하지 않습니다.
  • 광고 목적으로 사용자 데이터를 제공하지 않습니다.
  • 사용자 추적 또는 광고 프로파일링 목적으로 데이터를 공유하지 않습니다.
  • 개발자가 운영하는 별도의 서버에 사용자 데이터를 수집하여 보관하지 않습니다.

단, 확장 프로그램의 정상적인 기능 수행을 위해 사용자의 브라우저가 Suno의 웹사이트 및 API와 통신할 수 있습니다.

6. 다운로드한 파일

사용자가 다운로드를 요청한 음악 및 가사 파일은 Chrome의 다운로드 기능을 통해 사용자가 지정한 다운로드 위치에 저장됩니다. 확장 프로그램 개발자는 해당 파일을 별도의 서버로 업로드하거나 보관하지 않습니다.

7. 광고 및 분석

확장 프로그램은 광고 네트워크, 사용자 행동 분석 도구 또는 추적 서비스를 사용하여 사용자를 추적하지 않습니다.

8. 데이터 보안

인증 정보는 확장 프로그램의 핵심 기능을 수행하는 데 필요한 범위에서만 사용합니다. 개발자는 인증 정보를 별도의 서버에 저장하거나 제3자에게 판매하지 않습니다.

사용자는 자신의 Suno 계정 로그인 상태와 브라우저 보안 상태를 적절히 관리해야 합니다. 확장 프로그램 사용 전후로 본인의 Chrome 및 Suno 계정 보안 설정을 확인하는 것을 권장합니다.

9. 사용자의 선택 및 통제

사용자는 다운로드할 폴더와 곡, 파일 형식을 직접 선택할 수 있습니다. 확장 프로그램을 사용하지 않으면 해당 다운로드 기능을 이용하지 않을 수 있습니다. 또한 Chrome의 확장 프로그램 관리 화면에서 언제든지 확장 프로그램을 비활성화하거나 제거할 수 있습니다.

10. 어린이의 개인정보

본 확장 프로그램은 어린이를 대상으로 제작된 서비스가 아니며, 어린이의 개인정보를 의도적으로 수집하지 않습니다.

11. 개인정보 처리방침의 변경

확장 프로그램의 기능 또는 관련 법령과 정책의 변경에 따라 본 개인정보 처리방침을 수정할 수 있습니다. 변경 사항이 있는 경우 이 페이지의 시행일을 업데이트합니다.

12. 문의

개인정보 처리와 관련된 문의는 Chrome Web Store에 표시된 확장 프로그램의 개발자 지원 연락처를 통해 문의할 수 있습니다.

13. Suno와의 관계

Suno Downloader는 Suno의 공식 제품이 아니며 Suno와 별도로 제공되는 독립적인 Chrome 확장 프로그램입니다. Suno 이름 및 관련 상표와 서비스는 해당 권리자의 자산일 수 있습니다.

14. Chrome Web Store 정책 준수

본 확장 프로그램은 Chrome Web Store의 사용자 데이터 및 Limited Use 정책을 준수하는 것을 원칙으로 하며, 사용자 데이터는 확장 프로그램의 공개된 단일 목적에 필요한 범위에서만 사용합니다.
